# 迁移检查清单

> 按顺序勾选。每一行都对应一个真实踩过的坑，跳过就会返工。

## A. 侦察（不改代码）

- [ ] 确认教务是正方 jwglxt（URL 含 `/jwglxt/`）
- [ ] 抓包拿到课表 / 成绩 / 考试 三个响应体，存成样例文件
- [ ] 确认是否启用 MFA / 滑块 / 验证码
- [ ] 验证 Cookie 能否脱离浏览器 curl 成功（15 分钟内）
- [ ] 记录每校不同的 `gnmkdm` 值
- [ ] 确认学期编码：`xqm` 是 3/12/16 而不是 1/2
- [ ] 确认教学周起点日期（`term.startDate`）

## B. 接口层

- [ ] baseUrl 改为目标学校
- [ ] 所有 `gnmkdm` 替换
- [ ] 成绩 / 考试请求补 `queryModel.showCount=100`
- [ ] 需要排序的接口 `sortName` 保留末尾空格
- [ ] 仅在 query 生效的参数没放进 body（如 `xmlbfl`）

## C. 字段映射（逐条比对真实响应）

- [ ] 考试课程名用 `kcmc` 不是 `ksmc`
- [ ] 考场用 `cdmc` 不是 `cdbh`
- [ ] 考试类型用 `ksxz` 不是 `ksfs`
- [ ] `kssj` 用正则解析（兼容 `()`、`~`、`—`、`至`）
- [ ] 成绩 `cj` 兼容数字与"优秀/合格"文本
- [ ] 课表周次 `zcd` 展开为数组（支持 `1-4,6-7周`、`(单)`、`(双)`）
- [ ] 课表节次 `jcs`（"1-2"）与学校作息时间表对齐

## D. 缓存与并发

- [ ] 缓存键按学期隔离（`cache_<模块>_<termId>`）
- [ ] 字段语义变更时缓存键升版（`_v2`）
- [ ] 同名接口加单飞锁
- [ ] 大列表（>100 条）加内存层
- [ ] 全局刷新节流（2s）
- [ ] 演示数据不写真实缓存

## E. 数据正确性回归

- [ ] 切换 3 个学期，考试/成绩不串台
- [ ] 考试名称显示课程名（不是批次名）
- [ ] 考场显示楼名房号（不是编号）
- [ ] 成绩条数 = 教务网页条数
- [ ] 今日课表与教务课表一致（含单双周）
- [ ] 核心 GPA / 排名有合理兜底

## F. 多端

- [ ] 手机竖屏：底栏不遮挡最后一项内容
- [ ] 平板横屏：内容宽度舒适（不超 1100vp 行宽）
- [ ] PC 窗口拖到最窄：布局不错乱（设 minWindowWidth/minWindowHeight）
- [ ] 智慧屏：遥控器能到底栏、能打开快捷入口（focusable + onKeyEvent）
- [ ] 开源鸿蒙：无 `@kit.UIDesignKit` / `@kit.DeviceSecurityKit` / `@kit.ShareKit` 引用

## G. 权限与降级

- [ ] 日历权限被拒 → 提示且不影响其他功能
- [ ] 相册权限被拒 → 提示且可重试
- [ ] 通知权限被拒 → 应用内消息仍可用
- [ ] 防窥能力不支持 → 静默降级（不弹错误）

## H. 上线

- [ ] 应用名 / 图标 / 包名不沿用原项目
- [ ] 隐私政策与实际采集字段一致
- [ ] 未申请无关权限（尤其通讯录、位置）
- [ ] 关于页标注"非官方学生作品"
- [ ] 版本号与 Changelog 已更新
- [ ] 旧缓存迁移或升版策略已确认

## I. 发布物

- [ ] 签名包 `*-signed.hap`
- [ ] 网站下载链接与 version.json 指向新版本
- [ ] 包大小文案与实际一致
- [ ] 如需 OH 版：单独构建并标注差异
